# Security

If you believe you have found a security vulnerability in Cohervia, please report it privately through GitHub Security Advisories.

Please do not disclose exploitable details in public issues, pull requests, or discussions. Public issues should not contain vulnerability details that could be used to attack a system or exploit a weakness.

Use the repository's Security tab to open a private advisory if available. This allows maintainers to triage and remediate the issue without exposing the details publicly before a fix is ready.
