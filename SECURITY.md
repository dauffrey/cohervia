# Security

GitHub private vulnerability reporting is Cohervia’s supported vulnerability-reporting channel and must remain enabled for this public repository. To report a vulnerability, use `Security → Report a vulnerability`.

Do not disclose exploitable details in public issues, pull requests, or discussions. Public issues should not contain vulnerability details that could be used to attack a system or exploit a weakness.

If private vulnerability reporting is not enabled, the repository owner must enable it before this pull request is merged. Until that setting is verified, external reports should not be directed to a public issue or comment thread.
